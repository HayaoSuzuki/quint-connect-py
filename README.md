# quint-connect-py

Run Quint model traces against Python code.

Add it to the development dependencies of a uv project that targets CPython
3.14, 3.15, or both.

```sh
uv add --group dev quint-connect-py
```

For a new project, see the [installation guide](docs/user/guides/usage.md#install-with-uv).
If you already use 0.1, see the [0.2 migration guide](docs/user/guides/usage.md#upgrade-from-01).

Prebuilt wheels are available for Linux x86-64 (manylinux), macOS ARM64, and
Windows x86-64. Use Quint 0.34.0 to generate traces. Saved ITF traces can also be
replayed offline.
